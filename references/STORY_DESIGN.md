# Story Design for Historical Short Films

## 1. Start with a carrier, not a theme

Weak starting point:
- “讲120年校史”
- “展现学校精神”

Stronger carriers:
- one gate seen in different eras
- one letter traveling between places
- one student registration record
- one suitcase/book/bell/seal/nameplate
- one route across multiple campuses
- one family/alumnus/witness
- one repeated action: entering, leaving, rebuilding, teaching, writing home

The carrier gives the audience something to follow while the theme emerges.

## 2. Angle families

Generate concepts across different families instead of superficial variations.

### Object-led
A physical object accumulates meaning across time.

### Place-led
One place/building/gate becomes the witness.

### Person-led
One documented person or composite-free chain of real people carries the history.

### Question-led
The film begins with a concrete historical question and answers it.

### Journey-led
Movement through geography/time creates structure.

### Contrast-led
Past/present, departure/return, destruction/rebuilding, private/public.

### Document-led
A letter, register, photo caption, newspaper, archive number opens the story.

### Ritual-led
One repeated act—entering a gate, ringing a bell, reading a name, taking attendance—links eras.

## 3. Competition angle matrix

Score 1–5. Apply fatal evidence gates before ranking.

| Dimension | Weight |
|---|---:|
| Historical specificity | 20% |
| Emotional pull | 15% |
| Visual potential | 15% |
| Originality / memorability | 15% |
| Evidence strength | 15% |
| Production feasibility | 10% |
| Fit to brief / competition | 10% |

Weighted score = sum(score/5 × weight).

Fatal gates:
- core premise depends on an unresolved historical claim
- requires unavailable subject/location/rights with no alternative
- cannot fit runtime without becoming a montage of slogans
- ending has no payoff beyond a logo/slogan

## 4. One-sentence premise test

A concept is not ready until it can be stated as:

> By following **[specific carrier]**, the film reveals **[historical change/tension]**, leading the audience to understand/feel **[payoff]**.

Avoid premises that merely list coverage.

## 5. Narrative architectures

### A. Doorway structure
Present image → enter archival past → successive thresholds → return to present with changed meaning.

### B. Relay structure
Person/object/action passes from one era to the next.

### C. Mystery structure
Open with an unexplained image/object/name → investigate → reveal → reinterpret present.

### D. Return structure
Start from present-day ordinary scene → recover forgotten history → return to same scene with emotional transformation.

### E. Compression structure
Choose 3–5 decisive historical nodes. Each node must change the central question.

### F. Parallel structure
Intercut two eras/people/places around one repeated action or phrase.

## 6. Beat economy

For a 5-minute maximum film, do not assume every era deserves equal time.

Each beat must do at least one:
- open/complicate a question
- reveal evidence
- change location/time with purpose
- deepen human stakes
- transform the motif
- deliver payoff

If a beat only says “the institution continued to develop,” cut or concretize it.

## 7. Hook design

Historical-film hooks can be:
- an unexplained archival image
- a visual match cut past↔present
- a provocative factual question
- a close-up of a document detail
- an action already in progress
- a contradiction: “这扇门已经不在了，但……”

Avoid opening with full institution name + anniversary slogan + sweeping drone unless the brief explicitly requires it.

## 8. Motif system

Choose one dominant motif:
- gate/threshold
- footsteps
- names
- stamps
- handwriting
- maps/routes
- light entering a room
- bells
- books/pages
- water/ship/rail only if historically meaningful

A motif should **change meaning** through the film.

Example gate arc:
1. gate as architecture
2. gate as departure
3. gate as survival/rebuilding
4. gate as connection
5. gate as present choice: who walks through now?

## 9. Emotional curve

Use concrete emotional verbs:
- curiosity → recognition → rupture → persistence → return
- intimacy → loss → rebuilding → expansion → belonging

Do not label everything “感动/震撼/热血”. Define what causes the shift.

## 10. Endings

Strong endings:
- return to opening image with new meaning
- complete the object/person journey
- let archival voice meet present-day action
- leave one precise contemporary image carrying the historical theme

Weak endings:
- generic aerial montage + slogan
- list of achievements
- sudden logo with no narrative closure
