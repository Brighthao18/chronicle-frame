# ChronicleFrame v3.3.0

First public release — 2026-10-05.

ChronicleFrame is an evidence-grounded Agent Skill and production runtime for historical
short films. This release packages the tested internal v3.2.1 workflow for public use;
it does not reconstruct earlier public releases or Git history.

## Included

- A standard Python package and `hsd` CLI for initialization, validation, preparation,
  durable state, receipts, QC, previews, assembly and retained migrations.
- Generic project policy plus optional JSON profiles; the JNU gate example is isolated
  from the default runtime.
- Provider capability snapshots and truthful agent/tool/operator handoffs. No invented
  direct APIs, bundled credentials or mandatory cloud dependency.
- English and Chinese documentation, an original SVG project banner, a synthetic offline
  example, contribution guidance, issue templates and MIT licensing.
- Fast test CI on Windows and Ubuntu with Python 3.10, 3.12 and 3.13; a separate manual
  media workflow; fresh-wheel installation checks.
- Development/test extras include Pillow and NumPy for exact-pixel assertions; OpenCV
  and real encoding stay in the optional media layer. CI checks out the declared Skill
  directory name and uses UTF-8 on both supported operating systems.

## Compatibility

The public repository is named `chronicle-frame`. The Skill/distribution remains
`historical-shortfilm-director`, Python imports remain `historical_shortfilm_director`,
and the CLI remains `hsd`. Legacy scripts, schema migrations and production wire-format
aliases are preserved. Core commands have no third-party Python dependencies;
media extras and an external FFmpeg are optional.

## Validation and limits

Local checks passed: 54 fast tests, 6 real-media tests, the retained 41-method suite,
Skill validation, compile/import checks, lint/format, fresh-wheel installation,
generic and historical profiles, the offline preview and static privacy review.
The new suite preserves the original assertions; the counts overlap.

Cloud generation, authenticated provider-browser execution and creative quality were
not tested. The offline demo contains no historical claims and leaves human gates pending.
Technical PASS is not historical or editorial approval. See the
[migration report](../MIGRATION_REPORT.md) and [validation ledger](../validation-summary.json).
