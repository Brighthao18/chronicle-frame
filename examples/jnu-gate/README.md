# Advanced example: Jinan University gate motif

This historical-film example demonstrates profile templates, archival-region protection,
motif relationships, route preferences and project-specific QC. It is optional.
The generic framework works without this profile and without institutional knowledge.

```sh
hsd init --title "Gate motif study" --profile jnu_gate --dir work/jnu-example
```

The retained `jnu120` profile name is an alias. All profile behavior comes from
[`profile.json`](../../src/historical_shortfilm_director/profiles/builtin/jnu_gate/profile.json),
which is included in installed wheels. A frozen `00_profile.json` is written into each new
profile project so custom profiles can travel with a project.

The example's 300-second ceiling and orientation preference are demonstration constraints,
not a statement of current competition rules. No submission destination or deadline is bundled.
Legacy asset identifiers designate illustrative source groups; no corresponding private files
are included or inferred. Populate an evidence ledger from independently checked sources
before treating any historical assertion in the design notes as verified.
