## Recommended treatment for this concept

Avoid making the five gates five equal encyclopedia chapters.

Prefer:
1. **Present-day threshold** — a current student approaches/passes through a gate.
2. **First archival rupture** — match into an early gate/photo; ask why a school has had to pass through so many doors.
3. **Three to five decisive thresholds** — each gate must represent a different historical function, e.g. founding / relocation / wartime persistence / restoration / present connection, only where evidence supports it.
4. **Return to present** — the final gate is not just architecture; it becomes a question of who enters, leaves, returns, and carries Jinan outward.

Potential motif progression:
- 门 = 起点
- 门 = 离开
- 门 = 重建/坚持
- 门 = 连接
- 门 = 当下的选择

## Asset priority for this project

High-value assets to seek/verify:
- 1906 founding-era school gate image and provenance
- photographs/plans of later campus gates
- dated campus/location photographs
- maps showing relocations
- enrollment/administrative documents, letters, newspapers, school chronicles
- present-day matching viewpoints for past/present transitions
- clean scans rather than compressed reposts

An example 1906 gate restoration should be treated as a **reference/reconstruction asset**. Keep the original scan and provenance alongside any enhanced/generated version so the edit can distinguish source evidence from restoration/reconstruction.
